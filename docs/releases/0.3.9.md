# v0.3.9 — Photogrammetry Fast Ransac: Meshroom 2023.3's RANSAC counts as a template for 2025.1

Meshroom 2025.1 raised two RANSAC limits to 50,000: FeatureMatching's *Max Iterations* (2048 in 2023.3)
and StructureFromMotion's *Localizer Max Ransac Iterations* (4096). On every set measured that verifies
more weak pairs and places no more views, at a cost of minutes of matching. On Meshroom 2025.1, pairing
now adds two pipeline templates beside Meshroom's own, **Photogrammetry Fast Ransac** and
**Photogrammetry Draft Fast Ransac**. They are Meshroom's own Photogrammetry and Draft with the 2023.3
values set in the graph. On 884 photos, FeatureMatching takes 7.4 minutes instead of 29.6, with the same
views placed. Meshroom's own templates and the paired nodes' defaults are untouched.

The packages are 0.3.8's. Every binary is unchanged; the Windows zips carry the new pairing scripts.

## What changed

**The templates** (*File > New Pipeline*, and on Meshroom's home page):
- **Each is Meshroom's own template plus two lines**: FeatureMatching *Max Iterations* 2048 and
  StructureFromMotion *Localizer Max Ransac Iterations* 4096, set in the graph, where they show and can be
  changed like any other value. Everything else is Meshroom's.
- **Built from the Meshroom being paired**, so the node versions are always that Meshroom's, and checked
  to read as the stock graph plus those two values before it is written.
- **`--unpair` removes them.** A file of the same name that is not Cheshire's is left alone. Meshroom
  2023.3 gets nothing, since its defaults are these counts.
- **The same on both systems:** `meshroom-templates.ps1`, shipped beside `meshroom-pair.cmd` on Windows,
  and `meshroom-pair.sh` on Linux (which needs `python3` for this) write the same bytes.

**Why a template and not new defaults.** The paired nodes keep Meshroom's defaults, so a paired run of
Meshroom's own template gives what a stock Meshroom gives. A faster default would make a paired 2025.1
run differ from a stock one for a reason that is not Cheshire's code. The template makes the choice
visible instead.

**What the counts cost** (RX 9070 box, 0.3.8's binaries, which include 0.3.8's faster AC-RANSAC):

| | Meshroom 2025.1's defaults | Fast Ransac |
|---|---|---|
| 41 photos, the whole job | 378 s | 307 s |
| 41 photos, FeatureMatching / StructureFromMotion | 38.0 s / 65.7 s | 15.2 s / 18.5 s |
| 107 photos (engine bay), FeatureMatching | 373.8 s | 116.8 s |
| 107 photos, StructureFromMotion on the same matches | 35.3 s, 107 views placed | 15.1 s, 107 views placed |
| 884 photos (False Door), FeatureMatching | 1778.9 s | 443.0 s |

All 41 photos were placed with either. The larger budget verifies more pairs, weak ones; in 0.3.6's
measurements those placed no more views on the engine bay or the False Door.

**The template gives Meshroom 2023.3's result.** On 6 photos, the template's depth maps on Meshroom 2025.1
were byte for byte those of the same card's Meshroom 2023.3 run: on the RX 9070 and the GTX 1080 Ti under
Windows, and on the RX 6750 XT under Linux. On NVIDIA this comparison is possible since 0.3.8's PopSIFT
fix made CUDA runs repeat.

entry. The Linux tarballs are byte for byte 0.3.8's, since Linux pairing comes from the repository's
`scripts/linux/meshroom-pair.sh`.

## Validation

The binaries passed 0.3.8's full gate: 105 runs on five card configurations, none failed. For 0.3.9 the
gate gained a `fastransac` run, which builds its graph from the template by name, so Meshroom must list
it, and requires 2048 and 4096 in the two nodes' logged options. On Meshroom 2025.1, `base` now also
requires 50,000 in both, which proves the pairing leaves Meshroom's own template alone. The changed
packages ran as built:

| package | hardware | 2025.1: mini6 `base`, `fastransac` | 2023.3: mini6 `base` |
|---|---|---|---|
| Windows AMD | RX 9070 | both ok at 8/8 | ok at 8/8 |
| Windows CUDA | GTX 1080 Ti (bench-pc) | both ok at 8/8 | ok at 8/8 |
| Linux, repository pairing script (HIP tarball) | RX 6750 XT (house-pc) | both ok at 8/8 | ok at 8/8 in 0.3.8's gate |
